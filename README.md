# 论文写作技巧大合集（Paper Writing Toolkit）

一套按需调用的学术论文写作 Skill，覆盖选题收束、文献综述、证据核查、章节论证、引注检查与语言修订。适配不同学科，不替代作者的研究判断，也不生成虚构引文或数据。

## 使用

将本仓库的 `SKILL.md` 和 `references/` 目录一并安装到支持 Skill 的工具中。明确说“使用论文写作技巧大合集”或 `$paper-writing-toolkit` 才调用；普通论文请求不会自动触发。

示例：`使用 $paper-writing-toolkit 帮我检查这份论文提纲的论证链和证据缺口。`

## 内容

- `SKILL.md`：任务路由、核心流程、核验原则和学科适配
- `references/evidence-and-literature.md`：证据账本与文献卡片
- `references/revision.md`：分层修订清单
- `references/sources.md`：方法来源与再利用边界

本仓库只包含通用方法，不包含个人论文、私人通信或受版权限制的文献全文。使用或再分发前请阅读 `references/sources.md`。本仓库尚未选择独立许可证；公开可见不等于授予复制、修改或商业使用许可。
